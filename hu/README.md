# Operációs rendszerek

Egyetemi operációsrendszer-kurzus előadásanyaga, linuxos (x86-64) példákkal és laborfeladatokkal. Minden előadás saját mappában van: a szöveg a mappa `README.md` fájljában, mellette az ábrák (SVG) és a laborokban használt forrásfájlok.

Az előadások egyetemi hallgatóknak készültek, de minden rövidítéshez és szakkifejezéshez tartozik egy lenyitható **Egyszerűen elmagyarázva** doboz, így alapszintű számítógépes ismeretekkel is követhetők.

## A laborok futtatása

A laborprogramokhoz Linux (vagy WSL) kell `gcc`, `binutils` (`as`, `ld`, `objdump`) és `gdb` csomaggal. Debianon vagy Ubuntun:

```console
$ sudo apt install build-essential gdb
```

A 6. előadás `strace`-t és Python 3-at használ, a megfigyelési laborjához pedig root joggal `ltrace`-t, `perf`-et és `bpftrace`-t (`sudo apt install strace ltrace linux-tools-common linux-tools-$(uname -r) bpftrace`). A 7. előadás szintén `strace`-t, Python 3-at és (opcionálisan) Java JDK-t használ, a 8. előadás `valgrind`-ot (`sudo apt install strace default-jdk valgrind`). A 10. előadáshoz `e2fsprogs` (`debugfs`, `dumpe2fs`, `filefrag`), `dosfstools`, `xfsprogs` és `ntfs-3g` kell (`sudo apt install e2fsprogs dosfstools xfsprogs ntfs-3g`); az ext4-es bemutatók képfájlok csatolásához root jogot igényelnek. A 11. előadáshoz root jog kell (bemutató felhasználókat hoz létre), valamint a `libcap2-bin` és az `acl` csomag (`sudo apt install libcap2-bin acl`); a SELinux-laborhoz Fedora, RHEL vagy AlmaLinux virtuális gép kell. A 12. előadás kernelbeállításokat bemutató részeihez root jog kell, valamint a `libcap2-bin` csomag (`capsh`); a rendszerindítási laborokhoz UEFI-vel indított PC kell, a TPM-laborokhoz pedig a `mokutil` és a `tpm2-tools` csomag (`sudo apt install mokutil tpm2-tools`), vagy virtuális TPM-mel rendelkező virtuális gép. A 13. előadás namespace-, cgroup- és overlay-bemutatóihoz root jog kell, a konténeres laborokhoz Podman (vagy Docker), lehetőleg Fedorán, CentOS Streamen, AlmaLinuxon vagy Rocky Linuxon (`sudo dnf install podman skopeo buildah`); a KVM-laborhoz Intel VT-x-et vagy AMD-V-t támogató fizikai gép és QEMU kell (`sudo dnf install qemu-kvm libvirt virt-install`). A 14. előadás cgroup-, zram- és valós idejű bemutatóihoz root jog kell (a `chrt`, a `taskset` és a `swapon` a `util-linux` csomag része; a zram-bemutatóhoz zramot tartalmazó kernel kell), az androidos laborokhoz pedig `adb` (`sudo apt install adb`) és az Android Studio Android-emulátora vagy egy bekapcsolt USB-hibakereséssel rendelkező telefon.

A programok kimenetei és a bennük lévő megjegyzések angolul vannak; az előadásokban szereplő konzolkimenetek valódi, mért eredmények, ezért változatlanok.
