# Operating Systems · Operációs rendszerek

Lecture notes for a university Operating Systems course, with Linux (x86-64) examples, figures and lab exercises, in two languages.

Egyetemi operációsrendszer-kurzus előadásanyaga linuxos (x86-64) példákkal, ábrákkal és laborfeladatokkal, két nyelven.

| | |
| --- | --- |
| **[English](en/)** | fourteen lectures, from the history of operating systems through processes, memory, file systems and security to virtualization, containers and mobile, wearable and embedded systems |
| **[Magyar](hu/)** | tizennégy előadás, az operációs rendszerek történetétől a folyamatokon, a memórián, a fájlrendszereken és a biztonságon át a virtualizációig, a konténerekig és a mobil, viselhető és beágyazott rendszerekig |
